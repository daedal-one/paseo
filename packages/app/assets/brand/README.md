# Daedal-one assets

The mark comes from the daedal-one company graphics source `logo daedal (no text — duotone).svg`. The native logo component preserves its path geometry and uses the active foreground color with a secondary tone. Application icons use the company background variant; splash images use light and dark variants of the same geometry.

The product is Daedal DSH. Existing iOS application identity and compatibility identifiers are retained during migration. Upstream license and copyright attribution remain in the repository notices.
